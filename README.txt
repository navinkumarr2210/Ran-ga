RanGa White 3D Website – local test
1. Extract this folder.
2. Open Command Prompt/Terminal inside it.
3. Run: python -m http.server 8080
4. Open: http://localhost:8080

The home page has all six products permanently positioned around the RG circle (no product drop animation). Falling stars are background-only. All inner pages use the same white visual system, navigation, typography, shadows and sizing.
